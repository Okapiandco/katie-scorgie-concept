# Katie Scorgie website prototype

Open `index.html` to review the responsive Moving Canvas website direction.

Open `logo-options.html` to compare the three logo systems. All three retain Katie's supplied hand-drawn signature exactly as provided.

This is a static front-end prototype intended to establish visual direction before integration into the production Next.js and Stripe build. Enquiry links currently open email, the mailing-list form is demonstrative, and ecommerce links are placeholders pending product and Stripe data.
